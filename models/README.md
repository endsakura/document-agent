# 模型文件说明

本仓库**不包含** `best.pt` 权重文件（已通过 `.gitignore` 排除）。

## 使用者如何配置

1. 将你获得的 `best.pt` 放到此目录：`models/best.pt`
2. 或在 `.env` 中设置：`YOLO_MODEL_PATH=你的路径/best.pt`
3. 启动项目即可

## 作者如何分发模型（不公开在 GitHub）

可选方式（任选其一）：

- **私下发送**：网盘 / 邮件发给授权用户
- **私有仓库**：GitHub Private Repo 单独存模型（仅邀请协作者）
- **服务端部署**：模型只放在你的服务器，用户只访问 Web API，不拿到文件
- **带 Token 下载**：模型放 OSS/S3，启动脚本用密钥下载（密钥仅给授权用户）

> 注意：只要别人能在本机运行并拿到 `.pt` 文件，理论上都能复制。真正「看不到」需要改成**云端推理**，模型不离开你的服务器。
